# CostNest - Project Expense Tracker

CostNest is a comprehensive Android application designed to help users manage project budgets and expenses offline. It provides a clean, modern interface for tracking projects, tasks, and individual expenses, giving users clear insights into their spending habits and budget adherence.

## Features

-   **Project Management**: Create, edit, and delete projects with budgets and timelines.
-   **Task Tracking**: Break down projects into manageable tasks with individual budgets.
-   **Expense Logging**: Record expenses against tasks and projects to track spending.
-   **Visual Summaries**: View budget vs. spent analysis and expense distribution.
-   **Day/Night Mode**: Support for both Light and Dark themes for comfortable usage in any environment.
-   **Offline First**: All data is stored locally on the device (SQLite).
-   **Export Reports**: Export comprehensive project reports including tasks and expenses to CSV for external use.

## Setup & Installation

1.  Clone the repository.
2.  Open the project in Android Studio.
3.  Sync Gradle files.
4.  Run the application on an emulator or physical device.

## Technologies Used

-   **Java**: Core programming language.
-   **XML**: UI Layouts and resources.
-   **SQLite**: Local database for persistence.
-   **Android SDK**: Native Android development framework.
-   **Material Design 3**: Modern UI components and styling.
